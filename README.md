# Retail & Sales Data Analysis with Python

## Project Overview

This project was completed as part of a Data Technician Bootcamp and focuses on using Python for data exploration, cleaning, analysis, and visualisation of retail and sales datasets. Working within Google Colab, I applied a range of pandas techniques to transform raw business data into meaningful insights and identify trends that support data-driven decision-making. 

## Key Skills Demonstrated

### Data Exploration

- Loaded and inspected datasets using pandas.

- Investigated dataset structure, column types, and summary statistics.
  
- Explored retail and sales performance data to identify patterns, trends, and anomalies.
  
### Data Filtering and Selection

- Applied conditional filtering to isolate specific products, regions, customers, and sales periods.

- Used `.loc[]` for label-based indexing and row/column selection.
  
- Used `.iloc[]` for position-based slicing and data extraction.
  
- Created targeted subsets of data for focused analysis.
  
### Data Cleaning and Preparation

- Identified and handled missing values using:

- `dropna()`
  
- `fillna()`
  
- Removed unnecessary data and improved dataset quality.
  
- Formatted and prepared data for accurate analysis.
 
### Data Manipulation with Pandas

- Aggregated and summarised data using `groupby()`.

- Sorted records with `sort_values()` to identify top-performing products and regions.
  
- Applied additional pandas methods for filtering, reshaping, and transforming datasets.
  
- Generated business-focused summaries from large volumes of retail and sales data.
  
### Data Analysis

- Analysed sales performance across categories, regions, and time periods.

- Compared key metrics to uncover trends and patterns.
  
- Produced insights that highlight business performance and areas for improvement.
  
### Data Visualisation

- Created charts and graphs using pandas' built-in plotting functionality.

- Used matplotlib to visualise sales trends and key performance indicators.
  
- Developed visual representations of data to support analysis and communicate findings effectively.
 
## Tools & Technologies

- Python

- Pandas
  
- Matplotlib
  
- Google Colab
  
- Jupyter Notebooks
 
## Learning Outcomes

Through this project, I developed practical experience in:

- Data cleaning and preprocessing

- Exploratory Data Analysis (EDA)
  
- Data manipulation using pandas
  
- Working with retail and sales datasets
  
- Creating meaningful visualisations
  
- Extracting actionable insights from business data
  
This project demonstrates the application of Python-based data analysis techniques commonly used by Data Technicians and Data Analysts to transform raw data into valuable business intelligence.
